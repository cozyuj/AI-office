# LPC 캐릭터 에셋

이 폴더의 스프라이트는 [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator.git) 에서 `scripts/fetch-lpc.js` 로 가져온 것이다.
에셋마다 저자와 라이선스가 다르다 (CC0 / OGA-BY 3.0 / CC-BY 3.0 / CC-BY-SA 3.0 / GPL 3.0). 전체 목록은 `CREDITS.csv`.
이 프로젝트에서 재배포할 때는 CREDITS.csv 를 함께 배포하고, 가능한 경우 OGA-BY / CC-BY 조건(저작자 표시)을 따른다.
